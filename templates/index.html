PROJECT HIGHLIGHTS

DBMS Concepts Demonstrated

1. Relational Tables: Users, Stations, Chargers, and Bookings.

2. Primary Keys: Uniquely identify each record in a table.

3. Foreign Keys: Establish relationships between database tables.

4. SQL JOIN: Combine customer, station, charger, and booking details.

5. INSERT: Add new users, stations, chargers, and bookings.

6. UPDATE: Update booking status when a booking is cancelled.

7. UNIQUE Constraints: Prevent duplicate bookings for the same charger, date, and time.

8. Parameterized Queries: Pass user-provided values safely into SQL statements.
